# 1.0 回归检查清单

**引入新功能、重构或修复其他问题，必须测试老 Bug。** 先阅读 [Bug 复盘与历次解决方案](../BUG_REVIEW.md)，再执行本清单；新增测试不能代替旧事故回归。

执行 `npm run check`，同时检查真实浏览器报告和截图。`npm test` 单独执行构建一致性与 Node 行为测试。

- [ ] 用户输入与助手正文超过 3 行显示胶囊，展开后可收起；短消息没有无效按钮。
- [ ] 最新轮展开可关；全部折叠优先；流式正文原样显示。
- [ ] 滚轮不展开；长文末尾收起保留按钮位置；展开不跳到末尾。
- [ ] 正文前、中、后的图片完整显示；`picture/source` 保留；预览点击能打开原图。
- [ ] 多段步骤默认一个圆形双箭头；首次点击只显示各段开关，单箭头控制本段，箭头加横线控制所有内容；双箭头收回内容与开关。单段直接展开内容；组头不误开工具详情。
- [ ] 过程成员转最终回复后，旧隐藏标记完全清理，最终正文可折叠及查找。
- [ ] 原文原父节点未改变；宿主重绘、等长编辑、字体/图片加载、列宽变化后预览有效。
- [ ] 查找隐藏正文和步骤，命中字符进入视口并高亮；搜索不把预览重复计数。
- [ ] 顶部手柄可拖、可双击、可键盘操作，重载保留高度；工具按钮恢复原生底部间距，没有手柄产生的额外留白。
- [ ] 使用宿主「消息区和输入框共用滚动容器」布局，展开长步骤和长回复、流式追加或滚到历史中部，输入框保持贴底；外层临时保留旧高度时也不移到页面中间。
- [ ] 保存很高的输入区后缩小窗口、重载旧高度，工具栏仍在视口内且保留阅读空间；放大窗口恢复高度偏好。遮罩和非活动阶段使用原生布局，停用与卸载移除定位约束。
- [ ] 回答进行中持续追加正文、展开步骤并滚到中部/底部，发生输入框定位异常时临时恢复贴底；原生恢复后清除临时定位及等高预留区。只读输入区也能启动和恢复，恢复期间空闲无持续重绘。
- [ ] 回答结束后真实滚轮向上阅读，重复扫描、只读切换和输入框定位恢复均不写回阅读位置；测量过程中滚动范围不短暂缩小、阅读位置不被夹到尾部。
- [ ] 右栏关闭后第三列释放，打开恢复比例，禁用/dispose 恢复原宽度。
- [ ] 整轮 closed 后只在最后回复显示一个「本轮用时 X.X 秒」；中间工具结束不提前显示。
- [ ] 空闲至少 500ms 没有持续 DOM 写入；预览图 load 不形成重建循环。
- [ ] 服务晚到/卸载/重供正常，客户端失败不拖垮宿主；dispose 可重入且彻底还原。
- [ ] 对话菜单可打开带名称的删除确认框；取消零删除请求，连续确认只提交一次，失败不误报成功。
- [ ] 删除仅影响指定对话的本地历史及列表索引；工作区文件、附件、分支与其他对话保留；重启后目标历史不会再被加载。
- [ ] 正在处理、占用中的对话拒绝删除；不接受客户端路径，异常中断不会把局部失败显示成完整成功。

`test/rewrite-browser.mjs` 是上述浏览器行为的执行入口，`test/entry.test.mjs`、`test/rightbar.test.mjs` 与计时测试覆盖宿主生命周期。旧事故的历史说明保留在其他 docs 文件，若实现与旧记录不同，以本说明与当前行为测试为准。
