# dsh-fold-polish · UI 美化

DeepSeek Harness 的会话阅读插件，支持消息和工作步骤折叠、输入框调高、右栏宽度、折叠内容查找、每轮耗时，以及确认后删除本地对话记录。

## 使用

在「设置 → 插件 → UI 美化」调整选项；在右侧栏选择「查找」搜索本会话。

- **长消息**：用户输入和助手正文默认保留 **3 行文字**，点击带箭头的「展开我的输入 / 展开全文 · 还有 N 行」胶囊展开，点击「收起」折回。用户按钮靠右、助手按钮靠左。图片完整显示，不计入文字行数。滚轮和悬停不会触发展开。
- **最新一轮**：默认保持展开，也有手动收起按钮。可关闭「最新一轮保持展开」，或打开「全部消息都折叠」统一使用 3 行预算；后者优先。短消息无需折叠，正在输出的正文保持展开。
- **工作步骤**：恢复原来的两层交互。默认在步骤与回复之间显示细线和圆形箭头；多段步骤先只留一个双箭头，点击后显示各段开关，内容仍收起。单箭头展开本段，箭头加横线展开或收起所有步骤，双箭头「收起全部」将内容和开关一起收回。只有一段时，双箭头直接控制内容。关闭「默认只留一个按钮」后，各段开关直接显示。
- **输入框**：拖动卡片**顶部边缘**的手柄，向上拖增高、向下拖减小；双击恢复宿主自然高度。手柄不占布局空间，工具按钮保持原生底部间距。手柄支持方向键调高和 Home 复位。设置页也可输入像素高度，选择会保存。展开消息或步骤后保持贴底；窗口变小时自动限制实际高度，窗口放大后恢复保存的偏好。
- **右侧栏**：设置占整个应用框架的 30–70%。关闭右栏后，会话区立即回弹；重新打开沿用设置。实际宽度遵守宿主为会话保留至少 400px 的限制。
- **查找**：搜索已加载的用户输入、助手正文和工具步骤，包括折叠内容。点击结果会展开遮挡内容、定位到命中的文字并高亮。Enter 从首项开始循环，Shift + Enter 反向循环。更早的分页历史需先由宿主加载。
- **耗时**：确认整轮结束后，在最后一条回复末尾显示「本轮用时 X.X 秒」。使用宿主记录的最早处理开始时间和最后一步完成时间，包含工具执行；没有可靠时间的历史轮次不编造耗时。
- **删除对话**：在左侧对话菜单选择「删除对话…」，核对对话名称后选择「删除本地记录」。取消不作更改；正在处理的对话需等结束后再删除。删除后更新列表；工作区文件、附件和其他对话保留。

消息预览只截文字，保留全部图片。图片预览的点击会交给原图处理。含视频、画布、嵌入网页或表单的复杂正文保持完整，以保留原组件功能。

回答进行中也会检查输入框位置。检测到偏离会话底部时临时恢复贴底，宿主布局恢复后撤销临时定位；暂时不可编辑时仍保留高度手柄。

旧版默认的用户 6 行 / 助手 10 行在首次升级时迁移为 3 行；其他行数及高度偏好保留。

1.0.2 将 1.0.0 / 1.0.1 默认开启的步骤按钮文字恢复为关闭，回到原来的圆形按钮。需要文字时可重新开启「按钮显示文字」，使用带箭头的轻阴影胶囊。

## 本机和安装包

本机 desktop 配置链接到本源码目录。更新 `src/` 后执行构建，再重新加载插件或重启 DSH，宿主才会加载新的 `client.js`。

```powershell
npm run build
```

安装本地 `.tgz` 可使用宿主插件管理器。1.1.0 新增本地对话删除的服务端处理，升级后需要重新加载整个插件或重启 DSH。显示功能不修改模型请求；本地记录仅在确认删除时更改。

## 开发与验收

运行环境 Node >=20；开发测试使用 Node >=22（浏览器测试使用内置 WebSocket）和 Chrome/Chromium，无运行时 npm 依赖。

```powershell
npm run build
npm test
npm run test:browser
# 两部分加上构建一致性一起检查
npm run check
```

浏览器测试可设置 `CHROME` 指定可执行文件、`DSH_TEST_ARTIFACTS` 指定截图和报告目录。测试基于本机宿主 0.2.1-rc.2 核对的真实 DOM 契约，直接执行当前控制器，检查像素布局、鼠标操作、宿主重绘与卸载还原。它不向真实会话发送消息。

实现边界、生命周期与回归要点见 [DEVELOPING.md](DEVELOPING.md) 和 [回归检查清单](docs/回归检查清单.md)。
